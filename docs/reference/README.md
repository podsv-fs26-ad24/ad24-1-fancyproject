# Optional documentation (not required for module submission)

These Quarto sources are kept from the course template for reference. They are **not** published on the GitHub Pages site.

| File | Purpose |
|------|---------|
| `viz_design_report.qmd` | Visual encoding and design decisions |
| `evaluation.qmd` | Evaluation against project goals |
| `meeting_notes.qmd` | Team meeting notes |
| `deployment.qmd` | Deployment notes |

To preview one locally: `uv run quarto render reference/viz_design_report.qmd` from the `docs/` folder.
